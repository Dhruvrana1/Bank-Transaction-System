# Bank Transaction System

A backend application for managing users and bank transactions. This project provides APIs for user authentication and transaction-related operations.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Secure password handling
- Protected routes using authentication middleware
- Bank transaction management
- MongoDB database integration
- RESTful APIs
- Modular backend architecture

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- bcrypt
- dotenv
